## Brand & Style

This design system defines an ethereal, high-craft digital atmosphere built for an elite innovation and technology studio. The visual ethos combines deep, infinite atmospheric space with radiant, luminous structural elements. 

### Brand Personality & Emotional Impact
- **Luminary & Visionary:** Evokes the frontier of computing, bespoke software engineering, and bleeding-edge digital artifacts.
- **Architectural Precision:** Glass structures, razor-thin luminous edges, and disciplined geometry project absolute technical authority.
- **Atmospheric Depth:** Deep spatial field layered with chromatic dispersion, imparting feelings of immersion, prestige, and high-fidelity polish.

### Style Movements & execution
- **Dark Glassmorphism:** Layered surfaces constructed from translucent crystalline planes suspended over deep atmospheric radiance.
- **Chromatic Aurora Radiance:** Directional energy bleeds in violet, vivid purple, and spectral cyan that contour interaction zones.
- **Precision Minimalism:** Minimal non-functional chrome; content emerges through light, crisp borders, and refined hierarchy.

## Colors

The color system operates on an active canvas of infinite night, punctuated by chromatic flares and diffused refraction.

### Core Canvas & Obsidian Planes
- **Base Canvas:** Deep obsidian `#07060D` transitioning dynamically to elevated panel foundations `#0E0B1A`.
- **Surface Elevation Tiers:**
  - `surface-ground`: `#07060D` (Canvas background)
  - `surface-panel`: `rgba(255, 255, 255, 0.04)` to `rgba(255, 255, 255, 0.07)`
  - `surface-border`: `rgba(255, 255, 255, 0.12)`
  - `surface-highlight-top`: `linear-gradient(90deg, rgba(255, 255, 255, 0.28) 0%, rgba(217, 70, 239, 0.18) 50%, rgba(255, 255, 255, 0) 100%)`

### Aurora Chromatic Spectrum
- **Primary Energy:** Violet Purple `#7928CA` ramping into Electric Lavender `#8B5CF6`. Used for primary actions, focal rings, and interactive dominance.
- **Secondary Flare:** Vivid Violet-Magenta `#D946EF`. Used for high-energy state changes, gradient endpoints, and micro-accents.
- **Tertiary Resonance:** Deep Cyan `#06B6D4` fading into Sky Cyan `#38BDF8`. Reserved for ambient atmospheric backdrops, status gauges, telemetry values, and counterpoint balance.

### Text & Semantic Neutrals
- **Text Headings / Emphasized:** `#FFFFFF` (Solid light)
- **Text Body / Standard:** `#B8B3CC` (Refined lavender grey)
- **Text Muted / De-emphasized:** `#8A84A3` (Subdued twilight violet)
- **Interactive Focus Outline:** `rgba(139, 92, 246, 0.55)` with 8px spread blur.

## Typography

The typographic hierarchy utilizes geometric authority through **Sora** paired with technical precision and effortless legibility through **Inter**.

- **Display & Headlines (Sora):** Characterized by tight letter tracking, bold optical balance, and geometric forms. Large headlines set the tone of cutting-edge engineering. Use uppercase sparingly, primarily for section categorization markers or studio telemetry tags.
- **Reading Hierarchy (Inter):** Highly legible, neutral sans-serif that softens technical density. Long-form copy defaults to `#B8B3CC` with secondary details dropping back to `#8A84A3`.
- **System Labels & Metric Telemetry:** Micro-labels utilize uppercase styling with wider tracking (`0.06em` to `0.08em`) to convey engineering rigor, while code snippets and system values switch to a monospace companion.

## Layout & Spacing

The structural layout uses an expansive 12-column fluid grid system paired with strict horizontal rhythm, ensuring elements appear weightless yet mathematically anchored.

### Grid & Breakpoints
- **Desktop (1280px+):** 12 columns, 24px (`1.5rem`) gutters, dynamic margins maxed at 1440px inner container with `4rem` outer canvas padding.
- **Tablet (768px - 1279px):** 8 columns, 20px gutters, `2rem` outer canvas margin. Modular cards collapse from 3 or 4-column widths to 4-column pairs.
- **Mobile (< 768px):** 4 columns, 16px (`1rem`) gutters, `1.25rem` outer canvas margin. Complex glass telemetry stacks vertically with scrollable horizontal chip rails.

### Spacing Rhythms
- Spacing inside components follows multiples of 4px/8px.
- Use `space-lg` (`1.5rem`) for standard card interior padding; expand to `space-xl` (`2.5rem`) for high-profile hero glass panels.
- Content sections should maintain ample breathing room (`space-2xl` to `space-3xl`) to let ambient backdrops illuminate structural negative space without visual fatigue.

## Elevation & Depth

Depth in this system is created optically through glass refraction, luminous surface tiers, and physical light dispersion rather than standard drop shadows.

### Glass Architecture
- **Base Glass Structure:**
  - Background fill: `rgba(255, 255, 255, 0.04)` to `rgba(255, 255, 255, 0.07)`
  - Backdrop Blur: `20px` to `24px` (`backdrop-filter: blur(24px) saturate(140%)`)
  - Border: `1px solid rgba(255, 255, 255, 0.12)`
- **Luminous Edge Highlighting:**
  - Glass panels receive a pseudo-element top border: a 1px linear gradient spanning `rgba(255, 255, 255, 0.35)` down to `transparent`.
  - Inner glow: `box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.12), inset 0 0 24px 0 rgba(121, 40, 202, 0.04)`.

### Aurora Atmosphere & Glows
- **Ambient Light Fields:** Positioned under glass layers using radial blur filters (`blur(90px)` to `blur(140px)`). These fields use `#7928CA` (purple), `#D946EF` (violet-magenta), and `#06B6D4` (cyan) at 15–25% opacity.
- **Interactive Component Glows:**
  - Active/Hover Buttons: `box-shadow: 0 0 20px 0 rgba(217, 70, 239, 0.45), 0 0 40px 0 rgba(121, 40, 202, 0.25)`.
  - Focused Inputs: `box-shadow: 0 0 16px 0 rgba(139, 92, 246, 0.35), inset 0 0 12px 0 rgba(139, 92, 246, 0.15)`.

## Shapes

The design uses an organic yet sculpted pill-shaped geometry (`roundedness: 3`). Fully rounded silhouettes juxtapose the crystalline rigidity of glass panels to make interaction points instantly recognizable.

- **Primary Interactive Elements (Buttons, Search Bars, Badges):** Full pill rounding (`9999px` / `rounded-full`).
- **Surface Panels & Cards:** Softened structural rounding using `rounded-xl` (`1.5rem` / `24px`) to `2rem` (`32px`), producing smooth refraction corners.
- **Nested Controls & Micro Elements:** Modulated between `0.75rem` (`12px`) and full pills for nested toggles, metric gauges, and data tags.

## Components

### Buttons
- **Primary Aurora Pill:**
  - Background: `linear-gradient(135deg, #7928CA 0%, #D946EF 100%)`.
  - Shape: Fully rounded pill (`border-radius: 9999px`), padding `12px 28px`.
  - Border: `1px solid rgba(255, 255, 255, 0.25)`.
  - Elevation: Soft outer glow `0 4px 20px rgba(121, 40, 202, 0.4)`.
  - Hover: Subtle scale transition (`scale: 1.02`), outer glow intensity expands with magenta diffusion (`0 6px 28px rgba(217, 70, 239, 0.55)`).
- **Secondary Glass Pill:**
  - Background: `rgba(255, 255, 255, 0.05)`, backdrop-blur `20px`.
  - Border: `1px solid rgba(255, 255, 255, 0.15)`.
  - Hover: Border switches to `rgba(139, 92, 246, 0.6)` with inner glow `inset 0 0 12px rgba(139, 92, 246, 0.2)`.

### Chips & Status Tags
- **Technology Badges:**
  - Compact pill shape, padding `4px 12px`, typography `label-sm`.
  - Background: `rgba(14, 11, 26, 0.65)`, border `1px solid rgba(255, 255, 255, 0.1)`.
  - Feature: Accompanied by a 6px glowing status dot (Cyan `#38BDF8` for active systems, Magenta `#D946EF` for studio alerts).

### Cards & Panels
- **Crystalline Glass Card:**
  - Background: `rgba(255, 255, 255, 0.04)` over `#07060D`.
  - Backdrop Blur: `24px`.
  - Borders: `1px solid rgba(255, 255, 255, 0.12)` with top specular highlight (`rgba(255, 255, 255, 0.35)` fade).
  - Internal Padding: `24px` to `32px`.
  - Content: Title (`headline-sm`, Sora), description (`body-md`, Inter `#B8B3CC`), and bottom technical readout.

### Input Fields & Controls
- **Input Fields:**
  - Pill or soft rounded (`rounded-xl`), background `rgba(255, 255, 255, 0.03)`.
  - Border: `1px solid rgba(255, 255, 255, 0.14)`, text color `#FFFFFF`, placeholder `#8A84A3`.
  - Focus State: Border color `#8B5CF6`, glow aura `0 0 14px rgba(139, 92, 246, 0.3)`.
- **Checkboxes & Radios:**
  - Glass base with custom gradient fills upon check (`#7928CA` to `#D946EF`).
  - Outer border `1.5px solid rgba(255, 255, 255, 0.25)`.

### Gauges & Telemetry Visualizers
- **Studio Performance Gauges:**
  - Circular or linear indicators displaying system velocity and project metrics.
  - Track: `rgba(255, 255, 255, 0.08)`.
  - Indicator: Gradient path from `#06B6D4` to `#D946EF` with a glowing trailing head.
  - Value typography: `code-tech` or `headline-sm` with tight tracking.

### Iconography
- **Visual Style:**
  - Strict `1.5px` stroke weight across a 24x24 grid.
  - Color defaults to `#B8B3CC` with interactive hover states igniting into `#FFFFFF` or glowing `#38BDF8`.
  - Clean geometric construction matching Sora's structural angles.
